# Nabricrochet 🧶👜
Bienvenido al repositorio oficial de **Nabricrochet**, una tienda especializada en bolsos y accesorios tejidos a mano con estilo, arte y dedicación.
## 💻 Descripción del proyecto

Este repositorio contiene el desarrollo de la página web oficial de **Nabricrochet**, que incluirá:

- Una página de presentación de la marca y su historia.
- Un catálogo visual con imágenes de bolsos tejidos.
- Un **carrito de compras funcional** que permitirá a los usuarios agregar productos y gestionarlos fácilmente.
- Integración futura de una **pasarela de pagos online segura** para realizar compras directamente desde la web.
- Un formulario de contacto para atención personalizada.
- 
## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap o Tailwind CSS
- Git y GitHub
